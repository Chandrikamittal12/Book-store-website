# 📚 Book Store Website

A modern **Book Store web application** where users can browse and explore books through a clean and responsive interface. The project focuses on creating a simple and user-friendly online bookstore UI.

## 🌐 Live Demo

🔗 https://book-store-website-puce.vercel.app/

## ✨ Features

* 📖 Browse different books
* 🔍 Explore book collections
* 📱 Fully responsive design
* 🎨 Clean and modern user interface
* ⚡ Smooth and fast user experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* React.js
* Tailwind CSS
